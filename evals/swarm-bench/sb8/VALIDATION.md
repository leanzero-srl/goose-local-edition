# SB-8 release validation

This is an uncalibrated scorer, not a measured model leaderboard. The compact single-service task replaces SB-7's multi-service implementation burden; runtime and token savings still require actual entrants.

The reference implementation uses a copy of the contract oracle. Its 1.0 alone is not independent proof. The separate geometry tests exercise explicit counterexamples over 100 seeds; a reviewer also checked the discriminating placements over 1,000 seeds. The browser grades the actual scene canvas, projected pixels and interactions, not an app-provided scene graph.

Actual mutated reference artifacts were run through HTTP and browser scoring: endpoint-only collision 0.594; centre-only support 0.317; long-way rotation 0.534; frozen rendered scene 0.277. The frozen scene lost actual picking, state motion and revision checks. Scoring was subsequently tightened with UI grip/release, orbit and zoom checks. Exact receipts are regenerated by the runner below.

Run `python3 -m unittest discover -s evals/swarm-bench/bench -p test_sb8.py`. Set GOOSE_SWARM_RENDER_NODE to Node with Playwright and installed Chromium, then run `python3 evals/swarm-bench/bench/score_sb8.py --tree evals/swarm-bench/bench/golden-sb8 --seed 7123 --reference --json-out /tmp/sb8-reference.json`. Model campaigns must use the desktop Benchmark view. No paid/model calibration was launched for this release.
