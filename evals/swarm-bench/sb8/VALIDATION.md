## 2026-09-20 compact calibration pass

The calibration objective is a compact task that distinguishes frontier implementations through correctness, not build volume or target-score penalties. The public app contract has not grown. Tier weights and critical multiplier floors are unchanged. The developing label remains sb-8.0-rc; standalone verdicts now retain hashes of the scorer, browser probe and oracle for exact provenance.

Added checks exercise requirements the prompt already states: semantic validation follows stale-revision rejection; malformed, semantic and stale failures do not consume IDs; concurrent identical submissions commit once; replay is independent of JSON key ordering and returns the original receipt after restart; the scene survives a vendor-down restart. The canvas minimum size is now observed.

Removed an unfair bracing test: its exact diagonal sample locations were never specified. Structural bracing remains part of the product brief, but this scorer no longer awards points for one undocumented placement. Browser command errors accept a changed visible status or alert, as the prompt permits. Selection, movement, external state and camera scenarios catch failures separately, preventing a missing selection label from suppressing independent motion/camera checks. Raw evidence is copied before effective no-WebGL gating, preserving repeatable evaluation.

Validation: reference seed 7123 scores 1.0000 through real HTTP, restart and Chromium. Eight Python geometry/scoring/transaction tests pass. Transaction controls execute temporary reference clones: unsorted receipt-body serialization fails durable_reordered_receipt while ordinary durable replay still passes; semantic-before-stale validation fails all three stale-precedence checks while ordinary stale and corrected-ID retries still pass. These tests run in about three seconds. Browser controls pass with status-only errors; removing the selection test ID fails both selection checks while UI motion, external cargo motion, orbit and read-only camera still pass. A combined missing-selection-and-X-input control also retains cargo/camera grades. UI operations have explicit five-second transport/readiness waits; a whole-probe timeout refuses a comparable score instead of overwriting boot evidence. Reproduce with bench/validate_sb8_browser_controls.py and the documented browser environment.
