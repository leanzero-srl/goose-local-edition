Free generation-receipt readback on the saved original runs confirms MiMo has 232/232 billed generation IDs and Sol has 70/70. MiMo session counters omit 1,320 prompt and 21 completion tokens. The fifth telemetry record is a completed title call with exactly those counts. Sol session counters omit 1,339 prompt and 5 completion tokens. Its first telemetry record is a completed Gemini fast title call with exactly those counts. The cached residual is zero for both. The session titles persisted in sessions.db are consistent with those calls.

The causal source path is `session/session_naming.rs::generate_session_name` -> `model_config.rs::complete_fast`: title generation reads the returned message but discards ProviderUsage. `session/session_manager.rs` writes the resulting title, without `agents/reply_parts.rs::update_session_metrics`. Provider telemetry records these ordinary OpenRouter calls and OpenRouter bills them, so subtracting every bill from the smaller session totals yields a negative residual even when every paid call was recovered.

The new branch does not ignore negative differences. It accepts them only when all residual fields are nonpositive, cached residual is zero, telemetry covers every recovered generation ID, all calls have known end states, telemetry has no ID-less/malformed/unmarked/conflicting call, and every completed generation's native prompt/completion counts exactly match its corresponding provider receipt. Missing bills still refuse independently. Positive residuals remain incomplete. Negative cached residuals remain unproven because the provider telemetry does not record cached tokens per call.
