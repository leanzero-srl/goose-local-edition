Build a CLI template engine "tmpl" in Python — implement the parser + renderer yourself (do NOT use jinja or any templating library). EXACT commands: 'tmpl render TEMPLATE_FILE DATA_JSON' (render the template with the JSON data as context, print the result); 'tmpl check TEMPLATE_FILE' (parse only; exit 0 if valid, non-zero with the error+position if not). Template syntax you must TOKENIZE and PARSE into an AST, then render: literal text; '{{ expr }}' variable interpolation where expr is a dotted path into the context (a.b.c) or a filter chain 'name | upper | default:"x"' (support filters upper, lower, length, default:VALUE, join:","); '{% if expr %}...{% elif expr %}...{% else %}...{% endif %}' (truthiness of a path; also support 'a == b', 'a != b'); '{% for item in list %}...{% endfor %}' (iterate a list path, item is bound in the loop body, support {{ loop.index }}). Nested blocks must work. Exit non-zero with a clear message + position on an unclosed block, an unknown filter, or a syntax error. Runnable as 'python -m tmpl'. pytest suite: interpolation + dotted paths, each filter, if/elif/else, for with loop.index, nested for-in-if, and that an unclosed tag / unknown filter exit non-zero. Target ~1000-1400 LOC (lexer, parser, ast, renderer, filters, cli).
