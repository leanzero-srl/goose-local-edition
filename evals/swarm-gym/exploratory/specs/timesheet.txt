Build a CLI time tracker "clock" in Python backed by SQLite (global --db, default clock.db). ENTITIES: projects (name unique, hourly_rate) and entries (project, date, minutes, note). EXACT commands: 'clock init'; 'clock project add NAME [--rate N]' and 'clock project list'; 'clock add --project P --date D --minutes M [--note T]' (prints id; reject unknown project non-zero; reject minutes<=0 non-zero); 'clock start --project P [--note T]' (begin a running timer - store a start marker; reject if a timer is already running, non-zero) and 'clock stop' (close the running timer into an entry with the elapsed minutes; reject if none running, non-zero); 'clock list [--project P --from DATE --to DATE]'; 'clock today'; 'clock week --week YYYY-Www' (minutes per project for an ISO week); 'clock report project --from --to' (total minutes + billable amount = minutes/60*rate per project); 'clock export CSV' and 'clock import CSV' (round-trip entries). Validate inputs and dates; exit non-zero on bad input. Runnable as 'python -m clock'. pytest suite: add projects, add entries, start/stop a timer (assert double-start and stop-without-start are rejected), check week + project report + billable math, export/import round-trip. Target ~1000-1400 LOC.
