Build a CLI content-addressed blob store "blobs" in Rust (cargo, no networking) in a store dir (global --dir, default .blobs). Model: 'put' hashes a file's content with SHA-256 and stores it once under objects/<hash> (dedup: identical content stored once); a names index maps human names -> hashes (append-only log replayed on startup). EXACT commands: 'blobs init'; 'blobs put FILE [--name NAME]' (store the content, print its hash; if --name, bind the name to the hash); 'blobs get HASH_OR_NAME OUT_FILE' (write the content to OUT_FILE; resolve a name to its hash first; non-zero if unknown); 'blobs cat HASH_OR_NAME' (print the content); 'blobs names' (list name->hash bindings, sorted); 'blobs ls' (list all object hashes with their byte sizes); 'blobs rm-name NAME' (remove a name binding, keep the object); 'blobs gc' (delete objects not referenced by any name binding; print how many were removed); 'blobs stats' (object count, total bytes, name count, dedup savings = sum of put sizes minus stored bytes). Validate inputs; exit non-zero on missing store or unknown hash/name. Integration test (tests/): init; put two identical + one different file (assert dedup: two objects not three); name bindings + get by name; cat; rm-name then gc removes the now-unreferenced object; stats correct. Provide Cargo.toml. Target ~1000-1400 LOC (hash/objects, index, commands, cli).
