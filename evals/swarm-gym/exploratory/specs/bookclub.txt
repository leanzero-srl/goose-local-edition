Build a CLI reading tracker "shelf" in Python backed by SQLite (path via a global --db, default shelf.db). ENTITIES: books (isbn unique, title, author, pages, genre, status: unread/reading/read) and reading-sessions (book, date, pages_read). EXACT commands (match precisely): 'shelf init'; 'shelf add --isbn I --title T --author A --pages P [--genre G]' (print "added <isbn>"; reject duplicate isbn non-zero); 'shelf list [--status S] [--genre G] [--sort title|author|pages]'; 'shelf show ISBN' (non-zero if unknown); 'shelf start ISBN' (status->reading); 'shelf log ISBN --pages N [--date D]' (record a reading session, add N to progress; reject if it would exceed the book's pages, non-zero); 'shelf finish ISBN' (status->read; reject if not fully read yet, non-zero); 'shelf progress ISBN' (pages read / total, percent); 'shelf stats' (counts per status, total pages read, average pages/session); 'shelf report genre' (books + pages read per genre); 'shelf export CSV' and 'shelf import CSV' (round-trip books). Validate inputs; exit non-zero with a message on bad input or unknown isbn. Runnable as 'python -m shelf'. Include a pytest suite: add books, start+log sessions, assert over-logging is rejected, finish only when complete, check progress + stats + genre report, export/import round-trips. Target ~1000-1400 LOC across modules.
