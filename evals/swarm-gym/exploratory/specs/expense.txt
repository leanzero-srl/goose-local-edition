Build a CLI expense + budget tracker "spend" in Python backed by SQLite (global --db, default spend.db). ENTITIES: accounts (name unique, opening_balance), categories (name unique, monthly_budget), and transactions (date, account, category, amount signed: negative=expense positive=income, note). EXACT commands: 'spend init'; 'spend account add NAME [--opening N]' and 'spend account list'; 'spend category add NAME [--budget N]' and 'spend category list'; 'spend add --date D --account A --category C --amount N [--note T]' (prints the new id; reject unknown account/category non-zero); 'spend list [--account A --category C --from DATE --to DATE]'; 'spend balance [ACCOUNT]' (opening_balance + sum of its transactions; all accounts if omitted); 'spend report month --month YYYY-MM' (per-category spend vs budget, flag categories over budget); 'spend report category --from --to'; 'spend export CSV' and 'spend import CSV' (round-trip transactions). Validate inputs, dates, and numbers; exit non-zero with a message on bad input. Runnable as 'python -m spend'. Include a pytest suite: add accounts+categories, post transactions, check balances, check the monthly report flags an over-budget category, check the category report totals, export/import round-trips. Target ~1000-1400 LOC.
