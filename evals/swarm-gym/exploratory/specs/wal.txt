Build a CLI write-ahead-log tool "wal" in Rust (cargo, no networking) over a single log file in a dir (global --dir, default .wal). Model: a WAL of length-prefixed records, each with a monotonically increasing LSN (log sequence number), a CRC32 of the payload, and the payload bytes; the reader validates CRC and stops cleanly at the first torn/partial record (crash safety). EXACT commands: 'wal init'; 'wal append PAYLOAD' (append a record, print its LSN); 'wal read [--from LSN] [--to LSN]' (print each valid record as "LSN\tpayload", stopping at the first corrupt/torn record); 'wal tail N' (print the last N valid records); 'wal verify' (scan the whole log; print OK + record count, or the LSN where corruption starts and exit non-zero); 'wal truncate --after LSN' (drop all records after LSN; keep the log valid); 'wal checkpoint OUT_FILE' (write a compacted snapshot = the latest payloads, then note this is a snapshot); 'wal stats' (record count, first/last LSN, file size, bytes-per-record avg). Validate inputs; exit non-zero on a missing log, a bad LSN, or detected corruption in verify. Integration test (tests/): init; append several; read + tail; verify OK; truncate --after and confirm read stops there; simulate corruption by writing garbage bytes and assert verify reports it non-zero and read stops cleanly before it. Provide Cargo.toml. Target ~1000-1400 LOC (record codec+crc, log reader/writer, commands, cli).
