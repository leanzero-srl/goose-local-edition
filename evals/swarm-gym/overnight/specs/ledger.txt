Build a double-entry accounting CLI "ledger" in Python backed by SQLite. CONCEPTS: accounts each have a name and a type (asset, liability, equity, income, expense); transactions have a date, a description, and two or more postings; each posting debits or credits an account by an amount; a transaction is only valid if total debits equal total credits (reject with non-zero exit otherwise). COMMANDS: 'account add NAME --type T', 'account list'; 'txn add --date D --desc TEXT --debit ACCT:AMOUNT --credit ACCT:AMOUNT [more --debit/--credit ...]' (prints the new txn id; rejects if unbalanced or an account is unknown), 'txn show ID', 'txn list [--account A --from DATE --to DATE]'; 'balance [ACCT]' (the balance of an account, or all accounts, respecting normal debit/credit sign per account type); 'register ACCT' (running balance of every posting to an account in date order); REPORTS: 'report income --from --to' (income statement: income minus expenses over a period) and 'report balance-sheet --at DATE' (assets, liabilities, equity with the accounting equation checked); 'export CSV_PATH' and 'import CSV_PATH' of transactions. Validate all inputs and dates; exit non-zero on bad input. Persist to a SQLite file (path via --db or a default). Include pytest tests that add accounts, post several balanced transactions, reject an unbalanced one (non-zero), check balances and the running register, check the income statement and that the balance sheet balances, and that export then re-import round-trips. Provide a runnable entry point. Target roughly 1000-1500 lines across multiple modules.
