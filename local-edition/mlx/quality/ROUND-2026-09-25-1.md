## 4. How others handle the same moment

- Row 1: LM Studio Bionic chooses a session's model and where it runs from the model picker inside the session; "Remote models appear only while the linked device is available" ([docs](https://lmstudio.ai/docs/bionic/models)).
- Row 2: LM Studio shows a "Processing prompt" percentage during prefill (and gets bug reports when it sticks at 0%) ([#1826](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/1826)).
- Row 3: ChatGPT's chat-history memory adds the relevant context itself at chat start; it never points the model at a tool to fetch it ([OpenAI](https://help.openai.com/en/articles/8590148-memory-faq)).
- Row 4: exo's cluster panel shows memory for each node, per device ([DevoxxGenie/exo](https://genie.devoxx.com/docs/llm-providers/exo)).
- Row 5: classic LM Studio printed measured tok/s and time to first token under each message; users filed a bug when Bionic dropped it ([#2337](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/2337)).
- Row 6: LM Studio's own tracker records that one request's prompt processing blocks others' generation, the moment our "ready" hides ([#1709](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/1709)).
- Row 7: `ollama ps` shows the context length actually loaded (CONTEXT column), with an open complaint that it does not say where the number came from ([docs](https://docs.ollama.com/context-length), [#18229](https://github.com/ollama/ollama/issues/18229)).

## 5. What I could not walk

- The menu-bar tray: read from mlxTray.ts and `mlxEngineActivity()` only (row 16 PLAUSIBLE). `mlxRemoteReport` and `mlxRestoreReport` are senders, not getters, so they returned nothing.
- Anything that changes state (Run, Stop, Measure speed, split, Link, Save): the move and split journeys are click counts, not outcomes.
- The Studio's own app, and the prefix-cache cause in row 8.
- "Use other provider" and "Build a recipe with the fleet (chat)".
- The compaction effect of the stored 128000 (row 7) needs a long session, which is a reliability-track run.
