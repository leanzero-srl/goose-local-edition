## 4. How others handle it

- #1: LM Studio treats a load that cuts off a generating model as a bug ([#671](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/671)); Ollama's stop waits for active connections ([#14364](https://github.com/ollama/ollama/issues/14364)).
- #2: `ollama ps` lists loaded models, processor and context from one source ([FAQ](https://docs.ollama.com/faq)).
- #3/#4: LM Studio shows tok/s, token count and TTFT per message; users filed it as a bug when a UI dropped them ([#2337](https://github.com/lmstudio-ai/lmstudio-bug-tracker/issues/2337)).
- #5/#6: Open WebUI puts a spinner beside a generating chat and files a bug when it is missing ([#30014](https://github.com/open-webui/open-webui/issues/30014)).
