## 4. How others handle it

- Row 1: ChatGPT keeps the partial reply and puts an inline error with Regenerate under it at once. It never promises a resume ([useaxentix](https://useaxentix.com/blog/llm/chatgpt-error-in-message-stream-meaning-and-fixes/)). Open WebUI prints the network error at the foot of the response ([#16224](https://github.com/open-webui/open-webui/discussions/16224)).
- Row 2: Ollama queues requests "until the new model can be loaded" ([FAQ](https://docs.ollama.com/faq)).
- Row 3: the LM Link FAQ says only that a crashed device "shows up as disconnected", with no reason and nothing about in-flight chats ([LM Studio](https://lmstudio.ai/docs/lmlink/basics/faq)). goose already knows more than that and should show it.
