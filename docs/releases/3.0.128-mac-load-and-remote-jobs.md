# 3.0.128 — every Mac shows its load, Macs can run each other's jobs, a hung peer no longer stalls chat

## What changed

- **Three load readings per Mac.** Each card under My Macs (and each Mac node card) now shows three bars:
  **Own use** (the highest of CPU, memory used and GPU, plus whether someone is at the keyboard or how long it has
  been idle), **AI inference** (engine requests in flight and router slots held) and **Jobs** (jobs from other Macs
  running there). The readings come straight from the Mac (IOKit GPU utilisation, HID idle time, memory footprint,
  power source, thermal pressure), with no shell-outs and no sudo. A Mac on an older build says it does not report
  load yet.
- **Remote jobs with ids.** Link can send a shell command or a prompt to another Mac. Each job gets an id
  (`jYYYYMMDDhhmmss-xxxxxx`) that shows under Jobs on the target's card and in the sender's list. Click an id to see
  its state, exit code and a live log tail, and cancel it (the whole process group on the target is stopped). Jobs
  are placed on the Mac that can best take them, and a Mac that cannot says why: jobs turned off, a benchmark
  running, too little free memory, its one heavy slot already held, on battery, too hot, lid closed and set to sleep,
  someone using it.
- **Off by default.** Settings on your own Mac card: "Run jobs other Macs send" (`LEANZERO_LINK_ALLOW_REMOTE_JOBS`,
  default off), what to do while someone uses the Mac (take jobs / only as a last resort / refuse; default last
  resort), when it counts as idle (default 300 s) and the memory floor kept free (default 20 %). A job that pushes the
  Mac past the floor is killed.
- **A hung peer no longer stalls chat.** The swarm router now gives each peer probe 3 s
  (`probe_timeout_s`, `GOOSE_SWARM_PROBE_TIMEOUT_S`) and cools a slow or refusing peer for 15 s across turns
  (`peer_cooldown_s`, `GOOSE_SWARM_PEER_COOLDOWN_S`), so routing moves past it instead of waiting. Benchmark runs
  (`GOOSE_SWARM_BENCHMARK`) route exactly as before.

## Verified

- Rust: `cargo fmt --check`, `clippy -D warnings` (leanzero-link, goose, goose-sdk-types), `cargo test -p
  leanzero-link`, goose `acp::server::link` and `providers::swarm_router` tests.
- Desktop: `pnpm run lint:check` (typecheck, eslint, i18n in all 15 languages) and the full vitest suite.
- The built app was launched and its My Macs card showed the three bars before publishing.
