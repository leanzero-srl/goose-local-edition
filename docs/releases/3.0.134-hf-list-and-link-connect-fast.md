# 3.0.134 — the Hugging Face model list and LeanZero Link connect in about a second, no more "Models 0"

A fix release on top of 3.0.133. It fixes the slow Hugging Face model list, a LeanZero Link connect that took half
a minute to show your other Macs, the sidebar flashing "Models 0" at start, and an app started from an ssh session
that could not connect Link.

## Hugging Face list and Link connect

- **One slow request no longer holds every other one.** goose answered all the app's requests from one queue, so
  a slow models read (a model folder on a network disk, for example) made everything else wait behind it. On one
  Mac the Hugging Face list took 42.6 s while the Hugging Face calls behind it take 0.7 s, and Link status took
  28-33 s. Each request now runs on its own, so the list waits only for its own calls.
- **The engine status check reads one model, not all of them.** The status poll used to walk every downloaded
  model and parse every index file just to find the selected one, several times a second. It now reads only the
  selected model, and parsed index files are reused until they change.
- **Settings are read once, not on every check.** goose re-read and re-parsed config.yaml on every setting lookup,
  dozens of times a second while Link and the engine were polled. The parsed file is now reused until it changes.
- **The Hugging Face list survives a slow or failing repo.** Model sizes are looked up with a 4 s limit each and
  cached for 30 minutes. One repo that fails no longer turns the whole page into "Browse failed".

## LeanZero Link

- **Your other Macs show Online as soon as they are reachable.** Each Mac in My Macs used to start Offline and
  wait for a full status poll (up to 5 s each) before turning Online. A Mac that Tailscale reports online, or that
  answers a connection, now shows Online at once; a Mac with nothing listening still shows Offline.
- **The menu bar updates right after Connect.** A Connect or Disconnect from the Link tab now refreshes the Mac
  lines in the menu bar at once instead of up to 30 s later.
- **Link connects when goose was started from an ssh session.** An app started with `ssh mac 'open -a "Goose
  Swarm"'` inherited the ssh session's environment, and Tailscale then refused to connect ("aborted, no changes
  made"). goose no longer passes that environment to Tailscale.

## Other fixes

- **No more "Models 0" at start.** The sidebar shows no model count until the models folder was actually read,
  instead of a false 0.
- **The debug build no longer crashes on its first requests** (a stack overflow in goose serve).

## Upgrading

Install over 3.0.133. Your settings carry over. Update every Mac you use with LeanZero Link: Macs on different
versions may not list each other.
