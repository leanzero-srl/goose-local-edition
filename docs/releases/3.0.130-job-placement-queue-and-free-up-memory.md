# 3.0.130 — where jobs run, a job queue, and Free up memory

## What changed

- **Choose where your jobs run.** Settings for jobs on My Macs has "Where my jobs run": My Mac first (the default,
  `local-first`) runs a job on this Mac when it has room, else on the other Mac with the most room; Other Macs first
  (`selfish`) sends it to the other Mac with the most room first and keeps this Mac free. The setting saves at once
  and sits in `~/.leanzero/node-limits.json` as `"strategy"`; the `LEANZERO_LINK_JOBS_STRATEGY` environment variable
  overrides it. The Run a job dialog can override it for one job when Best Mac is chosen.
- **Jobs wait in line instead of failing.** When no Mac has room, a job sent to Best Mac waits in a first-in,
  first-out queue on the Mac that sent it and starts on the first Mac that has room. The job row says "Waiting, #n in
  line", the job's dialog shows why each Mac said no and, once placed, "Placed on X". A waiting job can be cancelled
  (with a confirmation) before it ever starts.
- **Free up memory.** Each Mac card and the per-Mac load panel have a Free up memory entry. It lists what holds
  memory (goose's own engine and its whole process tree, other MLX engines, Ollama and LM Studio models, left-over
  goose servers, apps), says whether a model would fit after freeing, and frees it: unloads goose's idle engine, asks
  Ollama (keep_alive 0) and LM Studio to unload their models, stops proven left-over goose servers and, only when you
  confirm, quits apps. What was freed is measured per process until the numbers settle, not estimated. It works on
  another Mac over Link too; reclaiming there needs that Mac's model-management permission, and quitting apps on
  another Mac stays off unless that Mac sets `GOOSE_LINK_ALLOW_REMOTE_APP_QUIT`. Settings › App has its tunables.
- **Run a job lists every online Mac.** A Mac whose jobs switch is off is still listed in "Run on", disabled with
  "jobs are off on this Mac", instead of silently missing. Best Mac stays first. (D11)
- **The Run on field shows names.** It showed the raw value `__best__`; picking from any list field now shows the
  option's label. (D12)

## Verified

- Rust: `cargo fmt --check`, `clippy --all-targets -D warnings` (leanzero-link, goose, goose-server,
  goose-sidecar), `cargo test -p leanzero-link`, goose `acp::server::link`, `link_serve`, `swarm_router` and
  `memfree` tests, goose-server `remote_executor` tests, goose-sidecar `memfree` tests.
- Desktop: `pnpm run lint:check`, `pnpm run typecheck`, the full vitest suite, `pnpm run i18n:check` (16 locales),
  `just check-acp-schema`.
- Free up memory was measured live on two Macs before the merge (goose's own engine on one, an LM Studio model on
  the other): the reported freed amount matched the measured rise in free memory within normal noise.
