# 3.0.95 A slow Gauntlet build's score is kept, not discarded

**Re-scoring a build whose 3D view ran past the time limit now keeps the score.**

- **What happened:** in 3.0.94 the Gauntlet scorer scored such a build (GLM-5.3: 0.1457), but it still listed the setup step the timeout had prevented as missing infrastructure. "Re-score saved build" reads any missing-infrastructure entry as an unscored run, so it threw the score away.
- **The fix:** the step the timeout prevented is now recorded only with the timeout itself, so the score is kept and can be published.
- **Nothing else changes:** the task, the vendor and every check are the same.
