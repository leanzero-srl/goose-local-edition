# 3.0.27 My Macs · Models · Run it

Linked Macs are now three places instead of four scattered lists. My Macs shows one card per Mac under its own name — state in the colour palette, what it runs, free memory and disk, model count, chip — and on this Mac one switch, "Let my other Macs use this Mac", with three choices under it (load and download models, answer chat, run part of a split model); a Mac with a permission off says where to turn it on instead of showing a 403. Models is one table with a column per Mac: On disk, Loaded, Copying (Thunderbolt), Downloading, Not here, or Can't read with the reason, and the copy or download action sits in the cell; Hugging Face downloads choose the Mac. Run it, on the Engine tab, is the one way to start: on this Mac, on another Mac, or across both, each with its predicted speed; a missing model is copied first. The "Manage on" switch and the duplicate lists are gone; the tray has one line per Mac.

A split now reads blue with its prompt rate while it reads and green with tok/s while it writes, and serves Flash under Flash's own id.

Verified live on both Macs: My Macs and Models read both Macs (both models on disk on each); Run on Work's Mac Studio was ready in ~27 s and a chat from this Mac was answered there at 25.9 tok/s.

## Known

After Run on another Mac the Engine tile still reads "Stopped · this Mac", the serving line uses the Mac's network name, the split's Details open expanded, a split for a different model needs a trip into Set up, and a relaunch doesn't restore what was running. All five are in the next release.
