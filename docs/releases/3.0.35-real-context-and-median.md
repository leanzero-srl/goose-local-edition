# 3.0.35 The real context window, and the median of the runs

The chat's context counter now shows the window of the model that actually answers. With the 27B served from Work's Mac Studio it reads "0 / 262k", not the "0 / 128k" default it used when the app could not find a number. It follows chat when chat moves between this Mac, another Mac and a split across both. When no engine reports a window, the counter is hidden instead of showing a guess.

When the engine is idle, the Engine tile's big numbers are now the median writing and reading rates over the runs it saw, with the slowest–fastest range below them. That includes runs served while the Engine tab was closed, because the app's main process keeps the record. The menu-bar tray says the same: "Median of N runs: writes … (slowest–fastest), reads …".

Verified live on both Macs: after a reinstall the Studio's model came back by itself, the composer read "0 / 262k", and main's record held every run from chat turns sent with the Engine tab closed.
