# 3.0.137 — MiMo on two Macs, a Memory tab, and steadier long runs

Everything merged since 3.0.136 (`git log v3.0.136..v3.0.137`).

## Long agent runs

- **goose tells a budgeted session to wrap up.** When a session has a tool-call budget, goose now adds a wrap-up
  line as the budget runs low: finish what is in progress at 80 %, deliver the required outputs at 90 %, verify only
  in the last three calls. Version 2 of this nudge puts the files your request named but that do not exist yet first,
  and says one reply may write several of them. The system prompt tells the model to follow that line.
- **Compaction keeps the facts straight (round 6 and four follow-up fixes).** After a long chat is summarised, the
  kept block now states how many calls of the turn's budget were used and which wrap-up stage was reached; every
  call is counted in the folder it actually worked in; a failed call that a later call settled is one short line, not
  a repeated error; a failed shell call is judged by the step its exit code came from; failed look-ups (`ls`, `grep`
  finding nothing) are no longer listed as open errors; files under a temp folder such as `/private/tmp` are read
  again (the word "private" was mistaken for a secret); a reasoning summary starts at one of its named headings.
- **A misnamed edit parameter is read, not lost.** Some models send the edit tool `old`/`new` (or `old_str`,
  `new_string`) instead of `before`/`after`. goose now reads them when the declared field is missing and exactly one
  alias is present, and says so in the result. On the two-Mac split the tool-call reader no longer folds such a
  parameter into the value before it.

## Local engine and memory

- **A Memory tab** in the engine settings shows every engine memory tunable with its unit, range and live default,
  with presets, live validation, the derived maximum context and what stays free for macOS. Save keeps them; Apply
  restarts the engine only when you click it and never while requests run. The engine is now Rapid-MLX
  v0.14.3-lz.20, the first build that reads these settings.
- **macOS GPU wired limit.** The same tab shows the macOS GPU wired-memory limit per Mac, sets it behind the macOS
  administrator prompt, and can install or remove a boot-time daemon that re-applies it. It never prefills a value
  that would lower the limit macOS already allows, and warns if you type one.

## Two-Mac split

- **MiMo-V2.6 runs as a layer split across two Macs**, with goose planning the split (its own 5 % memory reserve,
  long contexts in smaller prefill chunks, ranks loading one at a time), reading MiMo's tool calls, thinking on agent
  turns, and reading images and video on the omni checkpoint. The split tells goose which reasoning controls it
  honours, so a benchmark run no longer dies on an effort level the split cannot translate.
- **Every Mac in a split shows the controller's tray status** with its own rank.
- **The memory hold is steadier.** The admission/hold check counts inactive pages, uses hysteresis, and acts on a
  sustained critical reading instead of the first one; the status card names the node and its numbers.

## Desktop

- **Audio is cut at a real pause.** Long clips are still heard in pieces of at most 30 seconds, but each piece now ends
  in the middle of the quietest 100 ms of its last seconds, not the quietest 20 ms, which could fall inside a word.
- **A running app checks for updates every 4 hours**, not only 5 seconds after start, so an app left open sees a new
  release the same day.

## Benchmarks

- **Gauntlet sb-7's money check grades the right payments.** `b_money_rendered` now checks each rendered cell
  against the payment that cell shows (joined by its pack row id), not against the first 50 payments of the pack. A
  cell with no pack row id scores 0, and the result says how many there were. This changes sb-7.1 and sb-7.2 scorer
  bytes, so those scores are not comparable with runs scored by 3.0.136 or earlier.

## Upgrading

Install over 3.0.136 (or let the app update itself). Settings carry over.
