# 3.0.8 Goose Swarm, CogniRunner task mode, knowledge from research, memory proposals

Two finished branches merged on top of 3.0.7 (984b75395): `feat/cognirunner-task-mode` (4cb53ddab) and `feat/knowledge-memory-events` (694435a28). Both merges were clean; the only files both branches touched were `Cargo.lock` and `crates/goose/src/lib.rs`, and git resolved them without conflict.

- The desktop app is named **Goose Swarm**: `productName` drives the bundle (`Goose Swarm.app`), Finder, dock, app menu and DMG volume; `appBundleId` stays `com.electron.goose` so an installed `Goose.app` updates through the same feed. Artifacts: `Goose-Swarm-3.0.8.dmg`, `Goose-Swarm.zip` / `Goose-Swarm-darwin-arm64.zip`, `latest-mac.yml`.
- CogniRunner task mode: `POST /cognirunner/tasks` on `goose serve` and `goosed`, signed receipt pushes (`x-cognirunner-signature: sha256=HMAC`), steer, cancel; proven offline with a mock provider and a local callback receiver (`crates/goose/tests/cognirunner_router_test.rs`).
- The OpenAI-compatible routes (`/v1/models`, `/v1/chat/completions`) are served by `goose serve`, the engine the desktop bundles; the surfaces live once in `crates/goose/src/api/`.
- A benchmark run is knowledge-blind (reads and writes nothing from memories/skills; `run_build.py` refuses an artifact whose knowledge store moved); what the research fan grounded becomes project-local knowledge.
- Memory proposals: the end-of-turn assessment judges the turn and proposes a memory; the desktop's proposal card offers Save / No / Edit; `memory_proposals` (default ON) and `assessment_model` config fields.

## Fixes made for the release

- `ui/desktop/src/utils/githubUpdater.ts`: the GitHub-API fallback updater matched the release asset by bundle name `Goose` — after the rename it would never find `Goose-Swarm.zip`. Now defaults to `Goose-Swarm`.
- `evals/swarm-bench/sb7.1/release-manifest.json`: the packaging hook verifies every frozen benchmark file's hash; `bench/run_build.py` changed (the knowledge-blind snapshot), so its hash was refrozen. Scorer bytes unchanged.
- `ui/desktop/src/utils/userDataPath.ts` (imported first by `main.ts`): Electron derives `userData` from the product name, so the renamed app started with an empty `~/Library/Application Support/Goose Swarm` beside the 1.2 GB `Goose` dir (settings.json, projects.json, recent dirs, window state, the renderer's localStorage, the benchmark work root). Found by launching the first packaged 3.0.8; pinned to `Goose`, gate re-run (lint:check exit 0, 2064 vitest passed), repackaged and re-notarized.
