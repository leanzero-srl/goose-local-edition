# 3.0.129 — remote jobs survive a Link reconnect, a Run a job dialog, Offline within seconds

## What changed

- **Jobs survive a Link reconnect.** The job registry now lives for the whole app, not for one Link session, so a
  Mac that drops and rejoins Link still lists its running jobs and can still cancel them. On start it also rebuilds
  from `~/.leanzero/jobs`: a shell job whose process group is still alive is adopted again (timeout, memory floor and
  cancel keep working, and the heavy slot is taken back); one that finished while nobody watched gets its real exit
  code, and one that vanished is marked lost.
- **Cancel answers the final state.** Cancelling a job waits for its process group to stop and returns the final
  state, or "Cancelling..." while it is still going down. The card hides the Cancel button meanwhile.
- **Run a job from the app.** My Macs has a Run a job dialog: the best Mac or a named one that takes jobs, shell
  command or prompt, heavy or not, memory needed and timeout. A refusal shows its reason in the dialog; on success
  the job's own dialog opens.
- **Prompt jobs have a log.** A prompt job now streams its run into the job log (the answer, tool calls with clipped
  results, and the finish), so the log tail shows what it did.
- **Offline within seconds.** A Mac whose Link drops shows Offline in about 2-3 s (two missed liveness looks), and
  the desktop refreshes the list of Macs every 1.5 s. A busy Mac that answers slowly is not marked Offline.
- **Benchmarks are recognised properly.** A Mac refuses jobs while the app's own benchmark runs (the app now leaves a
  marker for the run while it lasts) or while a process says it IS a benchmark. A process that only mentions the word,
  such as a prompt about benchmarks, no longer makes a Mac look busy. The refusal names the run instead of an
  interpreter path.
- **Clearer reasons and names.** "Heavy slot held" says who holds it and for how long, job rows show the Mac's name
  instead of its node id, and the jobs settings text now matches what the switch allows.
