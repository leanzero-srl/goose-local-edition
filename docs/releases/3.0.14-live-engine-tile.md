# 3.0.14 The MLX engine tile becomes a live instrument

The big status tile on Providers › LeanZero MLX (81bc87753) now shows the engine's own measurements, read from rapid-mlx `GET <baseUrl>/v1/status` by the main process on the view's 2-second cadence:
- Running: live generation tokens/sec in large type with a two-minute sparkline, Generating / Idle ("last run" when idle), one progress bar per request (completion of max tokens), "Reading prompt · 32k tokens" during pre-fill so the long silent start is visible, and GPU memory, prompt-cache hit rate and waiting requests.
- Mounting: memory claimed since the mount began against the model's size.
- Stopped: the chosen model's size against free unified memory with a fits verdict, and Mount on the tile.
- Failed: the engine's error and Retry on the tile.
An unreadable status says "Live stats unavailable" with the reason; nothing is simulated.
