Goose Swarm 3.0.1 refines Agent Work and MCP setup.

Agent creation now fills the workspace, with grouped settings, explicit tool selection and a configuration preview. Results appear as readable handoffs, while expandable activity retains tool inputs, outputs and failures. Stopped workers are marked interrupted. Project chat uses the same compact event treatment.

LeanZero MCPs have named configuration fields, connection tests and live tool discovery. Web Search can collect public pages into a research corpus with source and collection-date provenance. Those sources are available through the bundled agent tools. Secret fields remain protected when settings are reopened, and invalid configuration produces actionable errors.

Structured handoffs use the registered final-output tool name throughout the engine. Agent synthesis is grounded in delivered worker results, and only drafts backed by an actual successful worker draft can enter the approval queue.

Existing private agent workflows still require their own authentication and approval adapters; adding a directory does not automatically migrate those integrations.
