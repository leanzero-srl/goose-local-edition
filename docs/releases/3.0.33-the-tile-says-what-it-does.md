# 3.0.33 The tile says what the engine is doing

The Engine tile's headline is now what the engine is doing: Idle, Reading prompt, Writing or Queued. It used to say "Running" over a grey idle tile with "Idle" in small type in the corner, while the menu-bar tray already said "Remote · Idle". The badge on the Models and Sampling tabs uses the same word. The tile draws only figures that were measured. The writing-rate graph appears only while the engine writes; idle, it was a flat line with a dot that looked like a slider. There are no more dashes saying "nothing written" next to "2 requests served", or "no prompt read" next to "Reading prompt · 2m 37s". "0 prompt tokens from cache" is gone when it only repeats "0% of lookups hit". This applies whether the model runs on this Mac, on another Mac, or split across both.

A relaunch that brings a model back on another Mac no longer gives up while that Mac is still loading it. The check asked the other Mac twice, 17 ms apart, and the engine became ready in between; the two answers were read as "running but not serving". A "Could not restore" line now clears itself once the model serves. Under Run it, the plan is re-read whenever what serves changes, so a note from the loading moment no longer stays.

Verified live on both Macs with the 27B on Work's Mac Studio:

- Reinstalling both apps stopped the Studio's engine, and relaunching this Mac's app brought it back with no failure line.
- Idle, the tile reads "Idle" and shows only the counters.
- Through a chat turn it read "Reading prompt" (48.2K tokens, no dash beside it), then "Writing" in green at 33.0 tok/s with its graph and "Chat · Rhine River history".
