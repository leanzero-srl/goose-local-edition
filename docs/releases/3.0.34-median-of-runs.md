# 3.0.34 The median of the runs, not the last one

When the engine is idle, the tile's big number is now the median writing rate over every run the tile caught on that engine (for example "24.1 tok/s writing, median of 3 runs"). The median reading rate sits beside it. The columns below lead with the slowest–fastest range for writing and for reading, shown once the runs differ. Before, both numbers were the last run only, so one short, fast answer (51.4 tok/s) stood in for a model that writes at about 24.

A run is one request the engine reported. Its writing rate is the engine's own per-request rate; its reading rate is the prompt's uncached tokens divided by its time to first token. Runs are kept for one engine's life and dropped when the engine restarts. They now survive leaving the Engine tab and coming back.

The menu-bar tray says the same, for example "Median of 3 runs: writes 24.1 tok/s (22.0–51.4), reads 144 tok/s".
