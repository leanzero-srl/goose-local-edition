# 3.0.30 Run is a switch

A model now runs one way at a time. Pressing Run on another way (this Mac, another Mac, or across both) first stops the copy that is running and waits until its memory is free, then starts the new one. Before this, a second copy started next to the first and held its memory while chat kept going to the old one. The plan also counts the memory the running copy on another Mac would give back. It reads that from the engine's own figures, so "Run across both Macs" no longer says "short 5.2 GB on Work's Mac Studio" when the only thing in the way is the Studio's own copy of the same model.

When the model runs on another Mac, the Engine tile now shows its live rates: reading, writing, and the last run once it goes idle. Before, it read "Rates unavailable over LeanZero Link — engine returned 403" on every poll. The cause was a browser Origin header that the app added to its own background requests, which LeanZero Link's relay rightly refuses. A chat turn from this app to another Mac now shows as this app's chat on the tile, not as "a request not from this app's chats".

Also in this release (3.0.28 was built but not published):

- The Engine tile and the menu-bar tray follow whatever serves chat, including a model on another Mac, under that Mac's own name.
- The split's Details start folded.
- Run across both Macs switches the split to the chosen model by itself, with no trip into Set up.
- A relaunch brings back what was serving (this Mac, another Mac, or the split) and shows a line while it does.

Verified live on both Macs: see the release thread.
