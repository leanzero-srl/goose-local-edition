# 3.0.116 — benchmarks think at medium; Gemini 4 can think; the Benchmark form lists models

- Every benchmark entrant now runs at medium thinking, whatever the chat setting is. Before, no thinking
  level was sent at all, so each model ran on its provider's default; for gemini-4-argon on Google that
  default is near-zero thinking (42 thought tokens on a 301k-token request).
- Gemini 4 models are thinking models. goose matched the literal prefix "gemini-3", so the thinking
  selector offered only Off for Gemini 4 and any requested level was dropped.
- Gemini medium is sent as `medium` (it was sent as `low`).
- OpenRouter receives the thinking level for every model except one declared non-reasoning (it was sent
  only to models a name list recognised).
- Google's default fast model is gemini-3.8-flash (gemini-2.5-flash now answers 404).
- Benchmark view: Model ID lists the models the provider serves (typing any id still works), states when
  the list is loading, unavailable or failed, shows the model's custom fields, offers key setup in place,
  and states that every benchmark runs at medium thinking.
