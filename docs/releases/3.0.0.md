Goose Swarm 3.0.0 brings the accumulated Agent Work, memory and recall work into the desktop release, alongside the refreshed LeanZero MLX runtime and MCP navigation.

Model browsing now reports actual repository download bytes, matching the model card. Active downloads remain tracked across navigation. Shared buttons provide press, busy and error feedback, and route changes have a short two-geese animation with reduced-motion support.

Rapid-MLX is updated to upstream 0.14.3 with the LeanZero LoRA extension retained and tested, published as v0.14.3-lz.1. LeanZero Web Search and Documents MCPs ship with the app, including the browser used for PDF generation and page extraction. Web search requires a Serper API key; document tools and page extraction do not.

SB-8 is a compact backend-driven 3D gantry challenge with a new staged scorer, strong geometry and interaction weighting, transactional persistence and concurrency checks. It ships as an experimental, uncalibrated benchmark: reference and deliberately broken implementations were tested, but model runtime, token savings and difficulty rankings have not yet been measured.

The release also includes reviewed pending engine reliability nets, preserves explicit empty MCP selections, and stages manual updates in a private temporary directory. Updates continue to come from the LeanZero GitHub releases feed.

This release contains a Developer-ID signed and Apple-notarized macOS Apple Silicon app and disk image. Download Goose-3.0.0.dmg for installation; Goose.zip and latest-mac.yml serve the in-app updater.
