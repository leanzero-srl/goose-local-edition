# 3.0.115 — Gemini tool calls are requested in VALIDATED mode

Gemini 4 Argon, on the direct Google provider, sometimes generated a tool call the API rejected as a bare
"400: Request contains an invalid argument." — two benchmark runs died on it. goose now asks Google for
VALIDATED function calling whenever tools are offered, which keeps every call inside its declared schema
(9 of 9 replays of the failing requests succeeded, against about 1 in 3 before). Scorer files and the Forge 2.0
release manifest are unchanged.
