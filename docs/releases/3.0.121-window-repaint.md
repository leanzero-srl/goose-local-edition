# 3.0.121 — a window drawn only part of the way down is drawn again

## What happened

After long unattended benchmark runs on the Mac Studio, the Goose Swarm window was often left drawn only in part: the
sidebar reached the bottom, the main pane stopped about halfway down, and the rest showed the window's grey
background. The page itself was laid out in full (the routes fill the window), so the missing part was never drawn.

## The fix

- Goose repaints a window when it gains focus, is shown again (also when it stops being covered by another window) or
  restored, when a display is added or its resolution changes, and when the Mac wakes or its screen unlocks.
- While a window can be seen, goose also repaints it once a minute, so a stuck frame clears within a minute even when
  none of those events comes. A minimized or hidden window is left alone.
- Every GPU or renderer process that goes away is now written to main.log with its type, reason and exit code, so the
  next occurrence shows whether the GPU process died.

The cause is not proven yet. The same kind of failure in another Electron app on Apple Silicon clears with a repaint,
which is what this release does; the new log lines are there to confirm or rule out a GPU process crash.
