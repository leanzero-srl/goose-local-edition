# 3.0.90 Publishing runs with long recordings

A run whose graded browser recording is larger than leanzero.net accepts (4 MiB) can now be published. The app keeps the full recording and uploads a smaller copy: the same length and the same frames, at a lower resolution. The copy's caption names the SHA-256 of the graded original. The first publish of such a run re-encodes the clip and can take a few minutes; later publishes reuse it.
