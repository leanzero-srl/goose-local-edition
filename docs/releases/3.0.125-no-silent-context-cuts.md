# 3.0.125 — OpenRouter can no longer cut a conversation silently; runaway repeated replies are stopped

## What happened

A study of the Forge 2.0 benchmark builds (two independent builds per model) found that goose sent
`transforms: ["middle-out"]` on every OpenRouter request. That tells OpenRouter to compress a prompt that does not fit
instead of refusing it, and lets it route a long prompt to an endpoint that holds only half of it.

- **Tencent Hy4 preview, weaker build:** on 268 of 301 calls the model received about 5-9k tokens while the real history
  grew from 95k to 905k. It re-read its own instructions 51 times and reported work it had not done.
- **Grok 4.7, weaker build:** from call 182 the middle of the conversation was dropped. The last ~120 calls made no edits.
- **goose never compacted in either case.** It reads the provider's reported prompt size as the context size, and after
  a cut that is the size of what was kept, so the cut hid itself.
- **Grok's history held four 65,536-token replies of one repeated sentence.** Nothing in goose stopped a cloud model's
  runaway text.

## The change

- **Middle-out is off by default.** A new setting, `OPENROUTER_MIDDLE_OUT` (a switch beside the OpenRouter host
  picker), turns it back on.
  - Off, goose also disables OpenRouter's automatic compression explicitly
    (`plugins: [{"id": "context-compression", "enabled": false}]`). OpenRouter otherwise applies it to every endpoint of
    8k tokens or less.
  - A prompt that does not fit is refused, and goose compacts and retries. That now also happens when the refusal
    arrives after the stream has started.
- **With middle-out on, a compressed prompt can no longer hide.** When the billed prompt is under half of goose's own
  count of what it sent, goose logs `prompt_compressed_by_provider` and bases compaction on its own count and the size
  that was delivered.
  - That learned window is forgotten on the next uncompressed call or compaction.
  - Background calls (compaction, titles) are never read as a compressed chat.
- **Runaway text is stopped.** When the last 32,768 characters of a reply are one unit of 16-2,048 characters repeated
  exactly, goose stops the reply, keeps one copy in the history ("goose stopped this response …") and the turn goes on.
  - Text inside a code block never counts.
  - If the person asked for repeated output, the model is told to write it to a file with a tool.
  - Settings: `GOOSE_RUNAWAY_TEXT_CHARS` and `GOOSE_RUNAWAY_TEXT_COPIES`; 0 turns the watch off.
  - Swarm workers are exempt; the local engine keeps its own guard.
- **A refusal for length only resets the retry count when a call runs to its end.** A provider that streams a little
  and then refuses cannot loop compact → retry forever (2 tries, then the turn stops with a clear message).
- **Benchmarks:** an entrant's exported OpenRouter parameters never carry `transforms` or the compression plugin, so
  no benchmark run can be compressed. When the prompt fits, the only change to the request body is the explicit
  compression-off entry.

## Verified

- **Live OpenRouter probes:** the compression-off plugin answers 200 on MiniMax M3.1 Flash (free), Jev Router and
  DeepSeek V4.1 Flash 1017. An unknown plugin id is refused with 400, so the id is the one OpenRouter knows.
- **Tests that fail on the code before this change:**
  - the refusal, compact and retry path, both before and during the stream;
  - the compression safety net and its reset;
  - a window that no longer stays stuck at 76,843 after one compressed call;
  - the 7-to-2 sends on a mid-stream refusal;
  - Grok's real runaway unit tripping at about 37k characters instead of 287k;
  - "hello" ×5000, fenced CSV/JSON/bitmap/box output, zeros, progress bars, emoji and CJK, all left alone;
  - the watch switched off keeping every copy.
- **Two independent reviews (context and errors; runaway false positives):** eight defects confirmed, all fixed before
  release.
- **Gate:** fmt, build, clippy `-D warnings`. cargo test: goose 2,615 passed, plus 1 known environment failure
  (`test_codex_provider` needs this Mac's Codex login); goose-cli 958; provider crates 615. Desktop lint, and vitest
  5,056 passed.

## Behaviour change

Long OpenRouter chats that used to be compressed silently now compact visibly instead. Benchmark builds that were
silently truncated before this release (Hy4 preview's and Grok 4.7's weaker Forge 2.0 builds) measured goose with that
truncation; Hy4's pair is being re-run on this version.
