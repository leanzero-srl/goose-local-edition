# 3.0.113 — direct Google runs record their calls

A benchmark run on the direct Google provider (Gemini) now writes one telemetry line per model call, like the
OpenRouter, Bedrock and OpenAI-compatible providers already did. The Benchmark view's call counter and the published
entry's call count and token usage were empty for Google runs; they are now measured.

Scorer files and the Forge 2.0 release manifest are unchanged, so every published task fingerprint is preserved.
