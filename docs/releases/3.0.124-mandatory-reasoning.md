# 3.0.124 — Thinking Off works on models that cannot switch reasoning off

## What happened

With Thinking set to Off, every turn on MiniMax M3.1 Flash failed with "Bad request (400): Reasoning is mandatory for
this endpoint and cannot be disabled". goose sent OpenRouter `reasoning: {effort: "none"}` for Off whatever the model
declares, and OpenRouter's models listing marks this model's reasoning as mandatory.

## The change

- Before a turn goes to OpenRouter, goose fits `reasoning.effort` to what the models listing declares for the model:
  - Off on a model whose reasoning is mandatory sends the model's cheapest declared level (`low` on MiniMax), or the
    model's own default when it declares no levels. The chat says so once per model: "… cannot switch reasoning off,
    so Thinking Off runs it at its lowest level (low)".
  - Max sends the model's own top level (`max` on DeepSeek and MiniMax) instead of the fixed `xhigh`.
  - Every other level goes out unchanged. OpenRouter maps an undeclared level itself (a probe of `minimal` on MiniMax
    answered 200), and the benchmark pin (`medium`) reaches every model as before, so scores stay comparable.
- A reasoning setting of your own (OPENROUTER_PARAMETERS, or a saved per-model effort) is never raised by Max; only a
  `none` on a mandatory model is fixed.
- A routing variant such as `:nitro` is looked up by its listed id. If the models listing cannot be read within 10 s,
  the turn is sent as configured.

## Verified

- Live, MiniMax M3.1 Flash (free) with Thinking Off: 3.0.123 answers 400 "Reasoning is mandatory"; this build answers,
  with the notice shown once.
- Wire tests against a mock OpenRouter: Off/Max/Medium on MiniMax, Off/Max on DeepSeek, an unlisted model, a `:nitro`
  variant, a user's own effort under Max, one notice per model, and an unreadable listing. The wire test for Off fails
  on the code before this change.

## Behaviour change to note

Unpinned runs at the global Max now send `max` rather than `xhigh` to models that declare `max`, so they can cost more
and take longer than earlier xhigh runs.
