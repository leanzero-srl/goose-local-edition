# 3.0.10 Agent Work desk redone, an actionable "no model mounted" notice, one door per view

Four commits on top of 3.0.9 (c3bdb5196 … a3c58f7c3), all desktop UI; no swarm engine file touched.

- Sidebar: the pinned rows are MCPs, Skills, Memories, Providers. Agent Work and Benchmark lost their pinned rows (they duplicated their own sidebar sections); each section's title (`SectionTitleLink`) opens its view and carries aria-current while it is open.
- Chat: the swarm router's "no node can serve this turn" no longer lands as raw text. `NoNodeNotice` shows each node with its reason in words (the router's text verbatim under it), a Mount button for an MLX node whose saved model matches the device's served name, Open Providers, and Retry (resends the last user text).
- Agent Work desk: a status hero with one state-fitting primary action, a compact metric strip, needs-you only when something waits, the tick's phase anatomy timed from `tick_phase` events, the result first (finding, next step, sources, evidence collapsed), lane cards and the ledger. `?tick=N` now selects the tick shown. The page-wide horizontal overflow is gone (a non-wrapping "Last tick" value in the 340px column; a flex column that crushed the tick panel).
