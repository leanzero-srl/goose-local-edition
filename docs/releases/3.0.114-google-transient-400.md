# 3.0.114 — direct Google runs survive Google's transient 400

Google sometimes answers a valid request with a bare "400: Request contains an invalid argument." that names no
field; the same request sent again succeeds. goose treated every 400 as permanent and ended the session. That one
message is now resent like a server error; a 400 that names its cause still stops at once. Includes 3.0.113's
per-call telemetry for direct Google runs. Scorer files and the Forge 2.0 release manifest are unchanged.
