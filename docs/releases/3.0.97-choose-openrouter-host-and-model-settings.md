# 3.0.97 Choose the OpenRouter host, and set each model's own settings

**Pick which host serves an OpenRouter model, and test it from the app.**

- **What it does:** when you choose an OpenRouter model, in the cloud Providers dialog or the Benchmark form, the app lists every host that serves it, with its quantization, context and price.
- **Test before you run:** one click sends each host a real tool call and measures its speed, so a slow host or one that cannot call tools shows up before a run starts.
- **Pin a host:** the chosen host is saved and OpenRouter is told not to fall back to another, so a benchmark measures the host you picked.

**Each model's own settings appear as controls.**

- **What it does:** a model's custom fields, such as reasoning effort, show under the model in the Providers dialog and the Benchmark form. Models without any show nothing.
- **Where the fields come from:** OpenRouter models show the effort levels and options OpenRouter lists for that model. Other providers show goose's effort setting for models goose knows reason. LeanZero MLX already had its own Thinking and Effort controls in the Engine tab, and they are unchanged.
- **Saved per model:** a value is saved for that model only and sent on its requests. It wins over the global effort setting. Open chats keep the values they started with.
- **Benchmarks record what they sent:** a run's result shows the settings it used, for example "Model settings: effort low". Forge keeps its fixed effort, so its scores stay comparable.
