# 3.0.117 — local Liquid LFM models parse their tool calls

- The MLX engine pin moves to Rapid-MLX v0.14.3-lz.11. A local Liquid LFM2 / LFM2.5 model folder now gets the
  `lfm` tool-call parser and a reasoning parser from its own config and chat template. Before, the engine served
  every LFM tool call as plain text, so goose saw no tool calls at all.
- Process teardown waits on elapsed time, not a count of sleeps (the grace before a forced stop ran ~2.4x long
  when the app was started by launchd).
- The bundled benchmark kit is byte-identical to 3.0.116.
