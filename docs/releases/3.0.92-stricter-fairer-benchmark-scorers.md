# 3.0.92 Stricter and fairer benchmark scorers

**Gauntlet 7.2 scores now separate builds that used to tie.**

- **What happened:** three different models all scored exactly 0.7990. The admission bands capped a run at a flat number no matter how much of the band it failed, and several checks were broken in the probe, so different builds collapsed onto the same cap.
- **Graded bands:** the 0.699, 0.799 and 0.899 bands are now graded. With n of a band's own checks failing, its cap is the band's cap minus 0.03 for each failure after the first, never below the next band down. 0.599 (a visible scene) stays all-or-nothing.
- **Capped finals:** a capped run keeps its own gradient below the cap: final = min(earned, cap − 0.05 × (1 − earned)). The final equals the cap only for a perfect build, so two runs never share a cap value by accident.
- **Probe fixes:** clicks, brushes and camera glides now aim inside the 3D canvas, and the notification feed is read in full. Framing is judged by the contract's own wording.
- **New checks the contract already required:** the scene must settle when idle after every interaction, picks and draws must stay correct after a batch of changes, field errors must name the right path, and the summary must stay fast under a burst.
- **Refund pairs:** a read taken during the first sync, before the app has fetched its reversals, no longer counts as a half-applied refund. The vendor documentation defines the atomic group over webhook events, not the initial download.
- **Slow 3D views:** the 3D probe now waits up to 480 s instead of 230 s. Real builds measured 258 s and 281 s on a quiet machine and were being refused instead of scored.

**Forge 1.0 is stricter without changing the task.**

- **Economy:** event handling is now graded against the true optimum, so an app that makes three times the Jira calls it needs loses points, even when everything it shows is correct.
- **Three scoring sites:** each run is scored on three seeded Jira sites. Correctness counts the worst site, and excellence counts the mean.
- **Stated rules now measured:** resolver errors, the numbers in the explanation, sort order, SKILL.md and an idempotent rerun are now checked. A rerun with nothing new must write nothing.
- **The production-robustness band counts defects, not rows:** one root cause that fails several rows of the band is charged once. It caps at 0.899 and drops 0.03 per further defect.
- **Capped finals:** the same rule as Gauntlet, final = min(earned, cap − 0.05 × (1 − earned)).

**Re-score saved builds with the new scorers.** "Re-score saved build" in the Benchmark view uses the scorers shipped in this version and republishes over the existing entry on leanzero.net, so no duplicate entries appear.
